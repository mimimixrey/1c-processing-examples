# Примеры внешних обработок 1С

Два демонстрационных примера для платформы **1С:Предприятие 8.3.6+**. Исходники написаны специально для портфолио и не содержат код или данные работодателей.

| Обработка | Задача | Исходник |
| --- | --- | --- |
| Предпросмотр загрузки TSV | Проверка строк, количества и дублей до записи данных в базу | [Модуль объекта](tsv-import-preview/МодульОбъекта.bsl) |
| Сверка количеств | Сопоставление учётного и фактического количества по коду с учётом повторяющихся строк | [Модуль объекта](inventory-reconciliation/МодульОбъекта.bsl) |

Обе обработки не изменяют данные информационной базы. Первая возвращает подготовленные строки и ошибки загрузки, вторая — таблицу расхождений. Код не зависит от метаданных конкретной конфигурации: входные данные передаются в параметрах функций.

## Как собрать `.epf`

1. В Конфигураторе создайте новую внешнюю обработку для каждого примера.
2. Поместите соответствующий код в модуль объекта обработки.
3. Добавьте управляемую форму и вызов экспортной функции из её серверного кода. Выведите возвращаемые таблицы на форму.
4. Сохраните обработки как `.epf`, проверьте их на тестовой базе и только после этого добавьте файлы `.epf` в репозиторий.

В репозитории подготовлены **модули объекта**, а не собранные `.epf` с готовым интерфейсом. Код пока не запускался в платформе 1С, поэтому перед использованием требуется сборка и проверка в тестовой базе.

Для файлов с миллионами строк оба примера следует адаптировать: читать данные порциями, ограничивать размер промежуточных таблиц и по возможности переносить сопоставление на серверную сторону. Текущая версия показывает логику проверки и сверки на небольших наборах данных.
