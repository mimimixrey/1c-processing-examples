# Обработки 1С

Примеры кода для платформы 1С:Предприятие 8.3.

| Пример | Что делает |
| --- | --- |
| [Предпросмотр загрузки TSV](tsv-import-preview/) | Проверяет строки файла, количество и повторяющиеся коды до загрузки в базу |
| [Сверка количеств](inventory-reconciliation/) | Сопоставляет учётное и фактическое количество по коду позиции |

В каждой папке лежат модуль объекта и описание входных данных. Обе обработки возвращают результат для просмотра и не записывают данные в информационную базу.

Чтобы использовать код, создайте внешнюю обработку в Конфигураторе, поместите исходник в модуль объекта и вызовите экспортную функцию из серверного кода формы. В репозитории опубликованы исходные модули; файлы `.epf` не приложены.
