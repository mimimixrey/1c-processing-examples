# Сверка количеств

Функция `СверитьКоличества(ДанныеУчета, ДанныеФакта)` принимает две таблицы значений с колонками `Код` и `Количество`. Повторяющиеся строки одного кода суммируются, после чего рассчитывается отклонение: **факт минус учёт**.

В результате возвращается таблица с колонками `Код`, `КоличествоУчет`, `КоличествоФакт`, `Отклонение`, `Результат`. Позиции, которые есть только в одной из входных таблиц, также попадают в результат.

| Код | Учёт | Факт | Отклонение | Результат |
| --- | ---: | ---: | ---: | --- |
| A-01 | 10 | 8 | -2 | Недостача |
| A-02 | 0 | 3 | 3 | Излишек |
| A-03 | 4 | 4 | 0 | Совпадает |

Для этого примера в таблице учёта нужны строки `A-01 / 10` и `A-03 / 4`, в таблице факта — `A-01 / 8`, `A-02 / 3` и `A-03 / 4`. Создание документов по расхождениям зависит от конкретной конфигурации и выполняется отдельно.
