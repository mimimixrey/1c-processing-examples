# Сверка количеств

Внешняя обработка сравнивает учётное и фактическое количество по коду позиции. Экспортная функция `СверитьКоличества(ДанныеУчета, ДанныеФакта)` принимает две таблицы значений с колонками `Код` и `Количество` и возвращает таблицу:

`Код | КоличествоУчет | КоличествоФакт | Отклонение | Результат`

Повторяющиеся строки одного кода суммируются. Отклонение считается как **факт минус учёт**: положительное значение — излишек, отрицательное — недостача. Позиции, присутствующие только в одном наборе данных, тоже попадают в результат. Обработка не формирует бухгалтерские документы и не меняет остатки — это этап анализа расхождений.

Пример:

| Код | Учёт | Факт | Отклонение | Результат |
| --- | ---: | ---: | ---: | --- |
| A-01 | 10 | 8 | -2 | Недостача |
| A-02 | 0 | 3 | 3 | Излишек |
| A-03 | 4 | 4 | 0 | Совпадает |

Для создания документов оприходования или списания нужны правила конкретной конфигурации и согласованный бизнес-процесс; они намеренно не включены в этот независимый от конфигурации пример.

Чтобы проверить пример, создайте две таблицы значений с колонками `Код` и `Количество`. Для показанного результата в учётной таблице должны быть строки `A-01 / 10` и `A-03 / 4`, а в фактической — `A-01 / 8`, `A-02 / 3` и `A-03 / 4`. Затем вызовите `СверитьКоличества(ДанныеУчета, ДанныеФакта)` из серверного кода обработки.
