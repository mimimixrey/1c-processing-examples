# Предпросмотр загрузки TSV

Функция `ПроверитьTSV(ТекстФайла)` разбирает текст с колонками `Код`, `Наименование`, `Количество` (разделитель — табуляция). На вход передаётся содержимое файла, первая строка — заголовок.

На выходе — структура с двумя таблицами значений:

- `Данные`: строки, прошедшие проверку;
- `Ошибки`: номер строки и причина, по которой она не прошла проверку.

Проверяются число полей, обязательные значения, формат количества и повторяющиеся коды. Корректные строки можно использовать для дальнейшей загрузки.

В [sample.tsv](sample.tsv) есть две ошибочные строки: повтор кода `M-001` и текст вместо количества у `M-003`.
