# Предпросмотр загрузки TSV

Внешняя обработка проверяет текст табличного файла перед загрузкой в учётную систему. Формат: `Код`, `Наименование`, `Количество`, разделитель — табуляция. Первая строка содержит заголовок.

Экспортная функция `ПроверитьTSV(ТекстФайла)` возвращает структуру:

- `Данные` — корректные строки с колонками `Код`, `Наименование`, `Количество`;
- `Ошибки` — номера строк и описания ошибок.

Проверяются число полей, пустой код или наименование, числовое неотрицательное количество и повторяющиеся коды. Некорректные строки не попадают в `Данные`. Обработка ничего не записывает в информационную базу; после проверки пользователь может отдельно принять решение о загрузке.

Пример для проверки — [sample.tsv](sample.tsv). В нём строка с кодом `M-001` повторяется, а у `M-003` вместо количества указан текст. Оба случая должны попасть в таблицу ошибок.
